# Definition of Ready (Part 08)

A task only starts when it passes these eight items.
The DoD lives in the pull request template (`.github/pull_request_template.md`).

- [ ] Acceptance criterion written, with a negative case
- [ ] Feature risk classified in the matrix (critical, high or medium/low)
- [ ] Test scenarios written in Given / When / Then
- [ ] Files and modules involved identified
- [ ] ADR approved, if it touches schema or architecture
- [ ] Affected metric indicated
- [ ] Dependencies and blockers resolved
- [ ] Fits in up to 1 day
